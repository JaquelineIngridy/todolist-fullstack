# 📝 Gerenciador de Tarefas (To-Do List)

Uma aplicação completa para gerenciamento e organização de tarefas diárias, permitindo criar, visualizar, atualizar o status e excluir itens em tempo real.

---

## 🚀 Funcionalidades

- **Adicionar Tarefas:** Crie novas atividades para o seu dia a dia.
- **Listagem Completa:** Visualize todas as tarefas cadastradas em uma tabela organizada.
- **Controle de Status:** Atualize o progresso de cada item (ex: pendente, em andamento, concluído).
- **Data e Hora:** Visualização formatada do momento de criação de cada tarefa.
- **Exclusão:** Remova tarefas concluídas ou indesejadas com um clique.

---

## 🛠️ Tecnologias Utilizadas

- **Interface Visual:** HTML5, CSS3, JavaScript
- **Servidor e Regras:** Node.js, Express
- **Armazenamento:** Banco de Dados (MySQL)

---

## 📋 Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina:
- [Node.js](https://nodejs.org/) (versão LTS recomendada)
- [Git](https://git-scm.com/)
- Banco de dados configurado (MySQL)

---

## ⚙️ Como Executar o Projeto (Passo a Passo)

### 1. Clonar o repositório
Abra o seu terminal e rode o comando:
```bash
git clone [https://github.com/JaquelineIngridy/todolist-fullstack.git](https://github.com/JaquelineIngridy/todolist-fullstack.git)
```

### 2. Acessar a pasta do projeto
```bash
cd todolist-fullstack
```

### 3. Configurar e rodar o Servidor (Back-end)
Navegue até a pasta do servidor:
```bash
cd backend
```

Instale as dependências necessárias (o comando lê a lista de pacotes no arquivo `package.json` e baixa tudo automaticamente):
```bash
npm install
```

Inicie o servidor em modo de desenvolvimento:
```bash
npm run dev
```
> O servidor estará rodando em: `http://localhost:3333/tasks`

---

### 4. Abrir a Aplicação (Front-end)
1. Navegue até a pasta do visual (onde estão o `index.html`, `style.css` e `script.js`).
2. Abra o arquivo **`index.html`** no seu navegador de preferência (dê dois cliques nele ou abra através da extensão *Live Server*).
3. Pronto! A tela já estará conectada ao servidor para você criar e gerenciar suas tarefas.
